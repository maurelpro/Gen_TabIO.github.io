Aide — Moteur de formules

      
    

    


      

        
Principe

        
Chaque élément déclaré en Zone 1 reçoit une adresse calculée à partir de son index n
        (0, 1, 2 …) et des formules de la configuration. Le moteur n'autorise que des
        résultats entiers, positifs ou nuls, et travaille uniquement sur
        Input et Output — jamais de Mémoire.

      


      

        
Opérateurs autorisés

        

          
+Addition

          
-Soustraction (le signe unaire est accepté)

          
*Multiplication

          
/Division — le résultat final doit être un entier

          
%Modulo — reste de la division entière

          
( )Parenthèses — priorité d'évaluation

        

      


      

        
Variables autorisées

        

          
VariableTypeDescription

          
nintIndex courant de l'élément (commence à 0)

          
Input.COUNTintNombre d'entrées déclarées en Zone 1

          
Input.ADDRESS_STARTintAdresse de départ des entrées, encodée « à plat » : x·8 + y en format x.y, ou x en format y

          
Input.ADDRESS_ENDintDernière adresse générée des entrées (encodage à plat)

          
Output.COUNTintNombre de sorties déclarées en Zone 1

          
Output.ADDRESS_STARTintAdresse de départ des sorties (encodage à plat)

          
Output.ADDRESS_ENDintDernière adresse générée des sorties (encodage à plat)

        

        
Toute autre variable est refusée à l'analyse syntaxique et signalée sous le champ concerné.

      


      

        
Formats d'adresse

        

          
Zx.yex. E0.3, M10.5 — préfixe + octet + bit

          
Zyex. M10, M11 — préfixe + valeur seule

        

        
Z est le préfixe configurable (E, Q, M …). Si y atteint 8, la retenue est reportée
        automatiquement sur x : E0.9 devient E1.1.

      


      

        
Processus de génération — pour chaque index n

        
    
          
  1. Calcul du décalage : offset = formulaSTARTED(n)
    2. 
          
  2. Index effectif : n' = n + offset
    3. 
          
  3. Calcul de X = formulaX(n')
    4. 
          
  4. Calcul de Y = formulaY(n') — uniquement si le format x.y est actif
    5. 
          
  5. Addition de la Started Address : x = Started.X + X et y = Started.Y + Y
    6. 
          
  6. Construction de l'adresse finale : préfixe + x.y ou préfixe + x
    7. 
        

      


      

        
Règles de validation

        
    
          
  • Syntaxe vérifiée : seuls les opérateurs, parenthèses et variables de la liste blanche sont acceptés
    • 
          
  • Chaque formule est testée avec n = 0
    • 
          
  • Le résultat doit être un entier
    • 
          
  • Les valeurs négatives sont refusées
    • 
          
  • Les références circulaires via ADDRESS_END sont détectées
    • 
          
  • Un message d'erreur clair s'affiche sous le champ concerné
    • 
        

      


      

        
Exemple

        
formulaSTARTED = "0"
formulaX       = "(n - (n % 8)) / 8"
formulaY       = "n % 8"

n = 0 → E0.0      n = 1 → E0.1      n = 7 → E0.7
n = 8 → E1.0      n = 9 → E1.1

Astuce : avec formulaSTARTED = "Input.COUNT" sur la catégorie Output,
les sorties démarrent juste après la dernière entrée.

      


      

        
Structure de la configuration

        
{
  prefix: "E",
  started: { x: 0, y: 0, hasY: true },   // Started Address
  formulaSTARTED: "0",
  formulaX: "(n - (n % 8)) / 8",
  formulaY: "n % 8"
}
