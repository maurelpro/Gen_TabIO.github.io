Format de saisie

            
[INPUT]
nom_variable : commentaire
autre_variable : commentaire

[OUTPUT]
sortie_1 : commentaire

            
Variables disponibles dans les formules

            
    
                
  • n — index courant (0, 1, 2...)
    • 
                
  • Input.COUNT — nombre d'inputs
    • 
                
  • Output.COUNT — nombre d'outputs
    • 
                
  • Input.ADDRESS_START — adresse de départ input
    • 
                
  • Output.ADDRESS_START — adresse de départ output
    • 
            

            
Opérateurs

            
    
                
  • + - * / %
    • 
                
  • ( ) pour grouper
    • 
            

            
Exemples de formules

            
    
                
  • n — séquentiel simple
    • 
                
  • n % 8 — position dans l'octet
    • 
                
  • Math.floor(n / 8) — numéro d'octet
    • 
                
  • Input.COUNT + n — décalé après inputs
